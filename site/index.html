Quick Start in 3 Steps

Run in seconds with Docker Compose. Your cookie stays strictly on your machine.

1

Export J2TEAM Cookie

Login to Facebook as Group Admin. Use J2TEAM Cookies extension to export your session as JSON to cookies_fb.json.

2

Run with Docker

Mount cookie file read-only into container:
docker compose up -d --build

3

Automate via n8n

Call endpoints from n8n HTTP Request node or AI pipeline to inspect, approve, or decline posts automatically.
